# 🏥 诊所预约数据分析项目 (Clinic Appointment Data Analysis)

## 📖 项目背景
本数据集来自 Kaggle，模拟了一家诊所的 1000 条患者预约记录。
数据包含患者基本信息、预约日期、就诊日期、科室、医生、账单金额、是否需要随访等字段。
该数据集存在极高的数据“脏”度，包含日期格式混乱、货币符号混杂、分类变量表示不一致、大量缺失值等问题。本项目旨在通过完整的清洗、探索与建模流程，还原数据价值，并提供业务优化建议。

## 🎯 核心目标
1. **数据清洗**：处理乱码、缺失值、日期格式等，构建高质量的分析数据集。
2. **可视化洞察**：探索患者等待时间、科室分布、账单金额等关键指标，发现业务瓶颈。
3. **预测建模**：构建模型预测患者是否需要随访，并进行特征重要性分析。

## 📂 项目结构
- `03_Clinic_Project_Final.ipynb`：**核心交付文件**。包含数据清洗、可视化分析、预测建模全过程的完整代码与业务解读。
- `01_Data_Cleaning_Draft.ipynb`：数据清洗草稿（记录清洗逻辑），最终成果见 03 文件。
- `data/`：数据存放目录。
  - `messy_clinic_appointments.csv`：原始脏数据。
  - `cleaned_clinic_data_final.csv`：清洗后的干净数据（由代码自动生成）。
- `README.md`：项目说明。

## 🛠️ 数据清洗流程
在 `03_Clinic_Project_Final.ipynb` 中，我使用 Pandas 完成了以下核心清洗步骤：
1. **统一缺失值**：将 `"N/A"`, `"null"`, 空字符串等统一替换为 `NaN`。
2. **标准化分类变量**：对 `gender`（性别）和 `follow_up_required`（是否随访）进行小写转换、去空格及映射，统一为 `Male/Female/Unknown` 和 `Yes/No`。
3. **货币金额清洗**：利用正则表达式 `r'[^0-9.]'` 去除 `$`、`€` 等货币符号，并使用 `pd.to_numeric` 转换为数值类型，最后用中位数填充缺失值。
4. **日期转换与特征衍生**：使用 `pd.to_datetime` 处理多种格式的日期，并成功衍生出 `waiting_days`（等待天数）特征，为后续分析奠定基础。

## 📊 核心业务洞察 (EDA)
通过 Seaborn 和 Matplotlib 的可视化分析，我发现了以下关键业务洞察：
- **等待时间瓶颈**：骨科与神经科的平均等待天数超过 200 天，远高于其他科室。**建议：** 优先在这两个科室增加门诊频次，或引入分级诊疗机制。
- **高价值人群**：账单金额随年龄增长呈上升趋势，老年女性患者群体的平均账单最高。**建议：** 为该群体设计专项健康管理计划，提升客户粘性。
- **患者画像**：中老年患者占比最高，建议优化预约流程的易用性。

## 🤖 预测建模与反思
在预测“患者是否需要随访”的任务中，我使用随机森林进行了初步尝试：
- **模型结果**：随机森林模型的准确率为 `0.46`，特征重要性排序为：账单金额 > 等待天数 > 年龄。
- **深度反思**：
  1. 该数据集为模拟数据，目标变量与现有特征之间缺乏强相关性，导致模型很难学到规律。
  2. 随机森林在小数据集上容易过拟合，后续可尝试逻辑回归等更简单的模型。
  3. 特征数量过少（仅3个数值特征），未包含分类特征（如科室、性别）。下一步改进方向是引入 One-Hot 编码，并向业务方确认标签生成逻辑。
  *这个低准确率的结果让我深刻认识到：数据清洗与特征工程对模型效果的影响，远比单纯更换高级模型要大。*
